# نطاق | محول الصور لرابط

أداة Next.js تحوّل صورة أي منتج إلى رابط HTTPS مباشر وثابت جاهز للصقه في سلة وزد وShopify وWooCommerce.
**لا تحتاج أي مفتاح API أو خدمة مدفوعة أو قاعدة بيانات.**

## طرق الحصول على الصورة

1. **بحث تلقائي:** اكتب اسم المنتج، فيبحث الموقع في صفحة نتائج الصور العامة (Bing، ومع تعذرها DuckDuckGo) بدون مفاتيح، ثم يفحص الصورة الأصلية لكل نتيجة ويرتبها حسب الجودة والتطابق.
2. **لصق رابط:** الصق رابط صورة (مثلًا من صور جوجل عبر "نسخ عنوان الصورة")، أو رابط صفحة المنتج فيُستخرج منها `og:image` تلقائيًا. روابط `google.com/imgres` و`bing.com/images` تُفك تلقائيًا.
3. **رفع من الجهاز:** صورة من الجوال أو الكمبيوتر (تُحوّل HEIC وتُضغط الصور الكبيرة في المتصفح قبل الرفع).

زر **"افتح في صور جوجل"** يفتح نتائج جوجل في متصفحك. البحث داخل الخادم لا يستخدم جوجل مباشرة لأن صفحة صور جوجل لا تعرض نتائج بدون JavaScript، فلا يمكن قراءتها من الخادم بشكل موثوق.

## تحويل الصورة إلى رابط

`جلب الصورة -> فحص النوع الحقيقي والأبعاد -> تدوير وحذف بيانات الكاميرا وتصغير حتى 2000px -> رفع إلى Vercel Blob -> اختبار الرابط من الخادم -> READY`

- إذا منع الموقع الأصلي التحميل، يُستخدم تلقائيًا النسخة المخزنة لدى محرك البحث.
- الصورة نفسها لا تُرفع مرتين (مطابقة SHA-256).
- الرابط النهائي من تخزين المشروع وليس Hotlink من الموقع الأصلي، فلا يتعطل إذا غيّر الموقع صورته.

## التخزين (Vercel Blob)

كل شيء محفوظ في مخزن Vercel Blob المرتبط بالمشروع:

- `products/<sku-or-name>/<hash>.jpg` الصورة (رابطها هو الرابط النهائي).
- `meta/<hash>.json` بيانات المنتج والصورة (تُعرض في المكتبة وتُستخدم في Excel).
- `config/settings-*.json` الإعدادات.

عند ربط مخزن Blob بالمشروع من تبويب **Storage** في Vercel يُضاف `BLOB_READ_WRITE_TOKEN` تلقائيًا. هذا هو المتغير الوحيد المطلوب.

## Excel

صفحة `/import-excel`: ارفع ملف منتجات المتجر، اختر عمود الاسم وSKU ورابط الصورة (تُقترح تلقائيًا)، ثم صدّر `products-with-images.xlsx`.
الروابط تؤخذ من مكتبة الصور بالمطابقة عبر SKU ثم الاسم. الملف الأصلي لا يتغير، ويتغير عمود الصورة فقط.

## الجوال والأجهزة اللوحية

قائمة منزلقة وشريط سفلي على الجوال، بطاقات بدل الجداول، أزرار لمس 44px، حقول بخط 16px (بدون تكبير تلقائي في iPhone)، دعم safe area، وخط Tajawal مستضاف داخل المشروع.

## التشغيل المحلي

```bash
npm install
cp .env.example .env.local   # ضع BLOB_READ_WRITE_TOKEN من Vercel
npm run dev
```

## الأمان

- الموقع مفتوح بدون تسجيل دخول؛ أي شخص لديه الرابط يستطيع استخدامه وحذف الصور. لتقييد الوصول فعّل Password Protection أو Vercel Authentication من إعدادات المشروع.
- حد لعدد الطلبات في الدقيقة لكل عنوان IP على كل العمليات.
- حماية SSRF تمنع الوصول للشبكات الخاصة وlocalhost وmetadata endpoints، بما فيها صيغ IPv6 المدمجة.
- لا يُوثق بامتداد الرابط؛ يُفحص النوع عبر Magic Bytes وفك ترميز الصورة فعليًا.
